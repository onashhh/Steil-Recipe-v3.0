      Apple Safari blocks websites from opening the iOS Clock app directly. Use Apple Shortcuts or a native Lock-Screen Calendar Alarm below:

      How to set up "Steil Timer" in iOS Shortcuts (15 secs)
      1. Open the built-in Shortcuts app on your iPhone/iPad and tap +.
      2. Name the shortcut exactly: Steil Timer
      3. Add action: Start Timer → tap Duration → choose Shortcut Input (set unit to Seconds).
      4. Now tapping Start iOS Clock Timer above will trigger the real Apple Clock timer!
